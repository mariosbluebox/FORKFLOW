# Codex Notes

This folder is the shared memory for conversations between Mario and Codex on this project.

It is for collaboration notes, decisions, session summaries, and open questions. It is not production source code, and it should not replace `SPEC.md`, `SPEC2.md`, `PHASE4.md`, or implementation docs when those are the better source of truth.

## Structure

- `INDEX.md` lists sessions and decisions in chronological order.
- `working-agreement.md` describes how Codex should collaborate in this repo.
- `sessions/` contains concise summaries of important Codex conversations.
- `decisions/` contains accepted product and engineering decisions.
- `open-questions.md` tracks unresolved questions to revisit.

## Rule of Thumb

Keep this folder useful, not noisy. Prefer short summaries, clear decisions, and links back to the real project files.
